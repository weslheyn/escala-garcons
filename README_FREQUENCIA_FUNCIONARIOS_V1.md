# Atualização — Frequência Funcionários

Alterações aplicadas com cuidado no módulo de frequência:

- Renomeado de "Frequência de Salão" para "Frequência Funcionários".
- Cabeçalho atualizado para "CONTROLE DE FREQUÊNCIA FUNCIONÁRIOS".
- Adicionado filtro por área:
  - Todos os funcionários
  - Somente Salão
  - Somente Cozinha
- Adicionado filtro por horário:
  - Todos os horários
  - Abertura
  - Intercalado
  - Fechamento
- Mantido filtro por setor/função.
- Integração preparada para ler `colaboradoresSalao` e `colaboradoresCozinha` do payload oficial da escala.
- Identificação visual nos cards com etiqueta SALÃO ou COZINHA.
- Ações principais do card ajustadas para:
  - Presente
  - Falta
  - Atestado
  - Saída Antecipada
  - Registrar ação
- O botão "Registrar ação" abre as demais opções:
  - Férias
  - Troca de Horário
  - Troca de Folga
  - Medida Disciplinar
  - Banco de Horas
  - Desligamento

Não foram alterados os módulos de Eventos, Uniformes, Freelance, G's, Praças, Agenda ou Gerenciador de Tarefas.
