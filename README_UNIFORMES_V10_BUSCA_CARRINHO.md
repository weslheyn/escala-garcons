# Uniformes V10 - Busca + Carrinho de Entrega

Alterações:
- Campo de busca de uniforme separado da lista de itens da entrega.
- O uniforme só entra na entrega após clicar em + Adicionar.
- Bloqueio de duplicidade: se adicionar o mesmo uniforme novamente, soma a quantidade.
- Resumo automático antes de registrar, com total de peças.
- Mantido responsável pela entrega e nomes únicos de colaboradores.
- Ao trocar o setor, itens incompatíveis com o setor são removidos do carrinho para evitar erro operacional.
