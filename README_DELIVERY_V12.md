# DELIVERY v12 — Layout de referência aprovado

Base: v11 enviada pelo usuário.

Alterações somente em arquivos relacionados ao módulo Delivery:
- delivery.html
- delivery-dashboard.js
- delivery-premium.css
- sw.js (somente cache)

Principais ajustes:
- layout da Visão Geral reorganizado para reproduzir a referência aprovada;
- três gráficos alinhados lado a lado no desktop;
- região + turnos, status + tempos, raio + resumo + ranking, mapa + últimos pedidos;
- resumo do dia em largura total;
- horários do gráfico 'Pedidos por Hora' em posição vertical (90°), 00h–23h;
- ranking indicado como por pedidos;
- nenhum outro módulo funcional foi alterado.
