# DELIVERY V23

Alterações restritas ao módulo Delivery:
- Card da visão geral alterado de Pedidos por Região para Top Bairros, mantendo o tema escuro do dashboard.
- Top Bairros mostra Bairro e Pedidos, ordenados do maior para o menor e normaliza diferenças de maiúsculas/minúsculas.
- Gráfico Pedidos por Hora exibe somente Pedidos; série Entregas removida desse gráfico.
- Modo DIA do gráfico de tendência ganhou folga superior para não cortar os rótulos numéricos.
- Mapa inicia geocodificação automaticamente apenas para endereços novos ainda sem cache.
- Coordenadas já processadas são reutilizadas, reduzindo o tempo de atualização.
- Relocalizar Endereços permanece disponível para tentativa manual.
- Nenhum outro módulo foi alterado.
