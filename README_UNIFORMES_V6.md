# Módulo Uniformes V6 — Controle Completo Anápolis 2026

Atualização feita a partir da planilha oficial `UNIFORMES ANAPOLIS 2026.xlsx`.

## O que foi incluído

- 86 itens cadastrados automaticamente no app.
- Setores cadastrados: Administrativo/Caixa/Delivery, Almoxarifado, ASG, Bar, Brinquedoteca, Controle de Acesso, Cozinha/Pia, Cumim, Garçom, Manutenção e Recepção.
- Cada item possui: setor, grupo, nome, tipo, tamanho, ideal, estoque atual, em uso, lavanderia, comprar e status automático.
- Dashboard com estoque, em uso, lavanderia e compras.
- Estoque com filtro por setor e busca.
- Entrega/devolução para colaborador com baixa automática.
- Lavanderia com envio e retorno de peças.
- Lista automática de compras para copiar para WhatsApp.
- Histórico de movimentações.
- Firebase preservado no caminho `/uniformes_estoque`.

## Arquivos alterados somente no módulo Uniformes

- uniformes.html
- uniformes.css
- uniformes.js
- uniformes-seed.js
- README_UNIFORMES_V6.md

Nenhum módulo antigo foi alterado.
