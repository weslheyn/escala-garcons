# Uniformes V7 — Entrega com múltiplos itens

Atualização focada no problema operacional da entrega de kit completo para colaborador.

## O que mudou
- A tela Entregar / Devolver agora permite acrescentar vários uniformes na mesma movimentação.
- Exemplo de uso: entregar para um garçom um avental, uma gravata e uma camiseta branca no mesmo lançamento.
- Cada item tem sua própria quantidade.
- O sistema valida estoque de todos os itens antes de registrar.
- A baixa no estoque e o envio para histórico continuam item por item, preservando o controle por peça.
- Foi criado um lote interno da movimentação para agrupar os itens lançados juntos.

## Arquivos alterados
- uniformes.html
- uniformes.css
- uniformes.js

Nenhum outro módulo foi alterado.
