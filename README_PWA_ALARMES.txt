PWA ALARMES - GERENCIADOR DE TAREFAS

Esta versão reforça o funcionamento PWA:
- manifest atualizado;
- service worker atualizado;
- notificações via ServiceWorkerRegistration.showNotification;
- vibração via Notification.vibrate/navigator.vibrate quando o navegador permitir;
- cache dos arquivos de áudio salvos em assets/sounds;
- botão para ativar notificações do dispositivo;
- botão para testar alarme PWA.

Importante:
- PWA não é APK nativo. O navegador pode limitar som e vibração em segundo plano.
- Para melhor resultado no celular, abrir pelo Chrome/Edge Android e instalar na tela inicial.
- iPhone/Safari tem limitações maiores para som/vibração em segundo plano.
