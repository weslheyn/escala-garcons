# DELIVERY v13 — Revisão premium do dashboard

Base: v12 sem alteração de sw.js.

Arquivos alterados somente no módulo Delivery:
- delivery.html
- delivery-dashboard.js
- delivery-premium.css

Correções principais:
- tipografia mais leve e legível;
- horários 00h–23h na vertical com peso reduzido;
- mesmo padrão no modo DIA do gráfico temporal;
- legenda de plataformas completa (nome, pedidos e percentual);
- KPIs sem cortes de valores;
- grid sem espaços vazios;
- painéis mais compactos e alinhados;
- status, tempos, raio, turnos, ranking, mapa e últimos pedidos reorganizados;
- nenhum arquivo geral do aplicativo foi alterado.
