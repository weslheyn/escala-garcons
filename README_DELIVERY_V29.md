# Delivery V29 — bloco superior de Pedidos fixo

Alteração isolada no módulo Delivery.

Na tela PEDIDOS, durante a rolagem vertical, permanecem fixos:
- barra superior com Período, Referência, Comparar com e Atualizar Dados;
- título PEDIDOS e campo de busca;
- cabeçalho da tabela (Pedido, Data, Hora, Status, Turno, Motoboy, Cliente, Região, Plataforma, KM, Valor e Tempo).

Somente as linhas de pedidos rolam por baixo do bloco fixo. Nenhum outro módulo do sistema foi alterado.
