# DELIVERY v17 — KPIs e mapa de pontos

Base: v16 estável.

Alterações restritas ao módulo Delivery:
- delivery.html
- delivery-dashboard.js
- delivery-map.js
- delivery-map.css
- delivery-premium.css

Principais mudanças:
- removido o KPI 'Entregas Realizadas';
- 7 KPIs redistribuídos, com mais largura para Faturamento Total;
- mapa de calor removido;
- cada ponto real representa um pedido;
- cores dos pontos por plataforma;
- popup com pedido, cliente, horário, plataforma, região, motoboy, km, status, valor e endereço;
- filtros integrados ao mapa: plataforma, turno, status, região e raio;
- opções para agrupar pontos próximos e exibir/ocultar áreas;
- edição das regiões continua exclusivamente na aba REGIÕES;
- sw.js e demais módulos não foram alterados.
