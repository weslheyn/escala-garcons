# Módulo Uniformes V5 Premium Compacto

Correções aplicadas:
- Layout mobile e desktop reduzido, sem necessidade de zoom.
- Botões de exportação/planilha movidos apenas para Configurações e Relatórios.
- Entrada de estoque movida para a aba Estoque.
- Busca de funcionário com dropdown visual, compatível com mobile e desktop.
- Funcionários lidos de escala importada, base de freelances e cadastros avulsos do próprio módulo.
- Ao selecionar setor, os uniformes aparecem em lista suspensa filtrada por setor.
- Entrega/devolução em lote usando botão Adicionar, sem cards gigantes.
- Cadastro de item usando listas suspensas baseadas na planilha importada.
- Devolução mostra apenas itens que o funcionário tem em posse.
- Caminho Firebase preservado: /uniformes_estoque.

Nenhum módulo antigo foi alterado além dos arquivos próprios de uniformes.
