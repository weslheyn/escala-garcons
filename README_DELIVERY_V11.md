# Delivery v11 — Filtro temporal no gráfico central

Alterações somente no módulo Delivery.

- O gráfico central ganhou filtro independente: DIA, SEMANA e MÊS.
- DIA: mostra quantidade de pedidos por hora (00–23) na data de referência.
- SEMANA: mostra quantidade por SEG–DOM na semana da data de referência.
- MÊS: mostra JAN–DEZ, mês a mês, no ano da data de referência.
- O modo MÊS consulta o histórico mensal salvo no Firebase para compor o ano.
- Nenhum outro módulo foi alterado.
